# 气质来源：Polarsteps

参考图：https://mobbin.com/screens/389a26f7-bc37-4490-9b56-ba39414e71d1 （高清 1179×2676，不进仓库）

| 从图上读到的 | 怎么落的 |
|---|---|
| 白底 #FDFEFE、深海军蓝的字（量的，约 #001018） | Astryx 主题：页面底色、主文字色、强调色 |
| 每一站是圆到近似胶囊的白卡：细边、极轻的投影、上沿一线高光 | 圆角用 Astryx 的“页面级”一档（基数 6 → 42）；阴影换成主题里的轻阴影 |
| 圆角方形的缩略图，右下角压一个深色的序号圆点 | 图片位留空，放类型贴纸；序号圆点照做 |
| 一条虚线把各站串起来，线上有圆角方形的加号 | 路线虚线 + 两站之间的加号 |
| “建议”是虚线边框的卡，名字是珊瑚到橙的渐变字 | “想去”用虚线卡，名字用暖色渐变 |
| 底部一块深色区域托着两段切换，选中的一段是浮起的白胶囊 | 底部深色区 + 两段切换；内容区下沿做成大圆角压在它上面 |
| 日期是带下划线的小字 | 每站的时间带下划线 |
| 灰色胶囊里放状态（3/5 nights planned） | 头部“谁刚做了什么”用灰色胶囊 |

没有照搬的：Polarsteps 每站右侧是“加减晚数”，这里是“谁加的”头像，因为这个应用的重点是多人；它的圆润几何字体中文没有对应，用思源黑体的粗细对比代替。

规范（间距、圆角档位、字号）全部用 Astryx 的刻度；表单输入框和按钮直接用 Astryx 的组件。
