# fit-booking · 自由教练的约课应用

需求：学员端看课、约课、取消；教练端按小时放出时段、管理课程；状态自动流转；消息通知。
这是新流程的样例：**对着参考图做选择题 → 脚本生成样式 → 用通用零件拼界面 → 门禁核对与参考是否一致**。

打开：`npm install && RUN=runs/fit-booking npx vite`（地址加 `?skin=proto` 看原型）
在首页右上角切换“学员 / 教练”。

## 能做什么

- 学员：按天看课、搜索；看每节课的时间、内容、已约人数和还差几人开课；约课、取消；不能约时写明原因。
- 教练：选一天，点整点时段就开一节课，可选每周重复；补充名称、内容、人数上下限；手动开始、结束、删除。
- 约课、取消、删除课程都会在对方的消息里出现；课程状态随时间自动变化。

## 局限

- **没有课程照片**。参考（Equinox+）的质感很大一部分来自顶部的大照片，这里没有图片来源，所以没做图片位。这是和参考差距最大的一处。
- 没有查 Mobbin 的结构参考，结构直接来自用户的需求描述。
- 只做了按小时排课，需求里提到的 30 分钟粒度没做。
- 只有一位教练；学员端和教练端在同一台设备上切换身份来演示，没有服务端，通知不会真的发到另一台手机。
- 没有支付。
- 并排图只有搭建者自己看过，没有设计师评审。
