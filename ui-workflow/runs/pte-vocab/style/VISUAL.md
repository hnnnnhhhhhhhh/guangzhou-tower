# 视觉：ABY Journal

参考：`aby-timeline.jpg`（Mobbin 高清原图 1179×2676）、`aby-user-board.png`（用户提供的五屏拼图）

| 项 | 观察 | 对应配方 |
|---|---|---|
| 底 | 浅灰带一点冷色（约 #F1F1F2），不是白。背景里有大面积虚化的色团（timeline 顶部的模糊灰影） | `Screen` 的底与两个色团 |
| 面 | 白卡片，圆角很大（约 30pt）。没有描边，靠一层范围很大、很淡的弥散阴影浮起来，上沿有一线高光 | `SoftCard` |
| 层 | 底部输入框浮在内容上方，半透明白；内容滑到它下面时渐隐而不是被切（timeline 底部第三张卡的文字变淡） | `Screen` 的 dock 与渐隐遮罩；`Btn kind="soft"` |
| 字 | 标题两行同字号：上灰（Timeline）下黑（Today），中等字重，行距很紧。正文 16–17pt 常规字重 | `TwoToneTitle` |
| 色 | 几乎无彩色。彩色只出现在小胶囊上：浅色底 + 同色相深色字 + **虚线描边**（拼图第 3–5 屏的 Suggestions / Scan / Guided） | `Chip kind="dashed"`、`Btn kind="tint"` |
| 形 | 标签和筛选都是胶囊；时间戳是带小尖角的白色气泡；卡片内的次级标签是浅灰胶囊 | `Chip`（soft / bubble） |
| 动 | 从截图推断不出来。本次只做了卡片浮起和内容淡入 | `Deck`、`Reveal` |
| 记忆点 | ① 柔到几乎没有边界的白卡 ② 灰黑两行标题 ③ 彩色虚线胶囊 ④ 媒体选择器里的 3D 物件 | ①②③ 已做；④ 见下 |

## 素材（没做）

- 媒体选择器里的三个 3D 物件和斜放的黑色标签——需要设计师提供或另行生成。背单词用不到这个组件，本次没有对应物。
- 卡片里的 emoji 图标（云朵、祈祷手势）——本次用线性图标代替。
- 时间戳气泡的小尖角——`Chip kind="bubble"` 只做了圆角矩形，没有尖角。
