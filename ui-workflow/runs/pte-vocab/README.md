# pte-vocab · 一个真的能背单词的 app

需求：备考 PTE 的学术词汇背诵。这次走的是“先产品、后屏幕、再视觉”的新流程。

## 怎么打开

```bash
cd ui-workflow && npm install
RUN=runs/pte-vocab npx vite        # 然后用手机宽度打开它给出的地址
```

## 它能做什么

打开 → 首页告诉你今天要过几个词 → 一次一张卡：先回忆、看答案、自评 → 没记住的本轮再出现 → 小结 → 第二天回来，昨天的词到期复习，间隔按 1、2、4、7、15、30 天拉长。进度存在浏览器本地，关掉再开还在。可以朗读单词（用系统自带的语音）。

## 验证

`node scripts/gate-app.mjs runs/pte-vocab` → 26 ok · 0 warn · 0 fail

六条验收场景都是在真实浏览器里自动点出来的：首次学习、刷新后数据还在、第二天复习、复习时忘了、中途退出、加学一组并查看词表。

## 局限

- **只有 60 个词**（AWL 第 1 组），完整的是 570 个。释义和例句是这次编写的，没有经过教研审校。
- **只有一种题型**（看英文想中文、自评）。没有拼写、听写、选择题。
- **数据只在本机浏览器里**，没有账号和同步；没有提醒。
- **没有深色模式**。
- **视觉评审是搭建者自评**（10 / 12，见 `style/VISUAL.md`），应由他人复评。参考图里的 3D 物件和 emoji 没有做。
- 界面完全由 `recipes/` 搭成，没有用 Astryx 组件。
