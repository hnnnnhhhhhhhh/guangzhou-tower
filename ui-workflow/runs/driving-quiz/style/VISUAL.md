# 气质来源

参考：Commons 的答题屏，Mobbin 高清原图（1179×2676）
https://mobbin.com/screens/a965ec5f-871e-4a19-beb0-57552999f976
截图本身不进仓库。

| 从图上读到的 | 怎么落的 |
|---|---|
| 底是暖灰白 #F8F8F8，不是纯白（量的） | 主题：页面底色 |
| 选项是暖灰平块 #E8E7E3，没有描边、没有阴影（量的） | 主题：弱化底色；选项不加边框 |
| 选错的选项整块变粉 #F0BCB4（量的） | 主题：错误的浅色 |
| 进度是一条深蓝粗线 #000098（量的） | 主题：强调色；只用在进度、解析引线、选中 |
| 题干是极粗的黑色无衬线，行距很紧 | 题干用最重的字重 |
| 选项文字是衬线体，和题干形成对比 | 选项、正文用思源宋体 |
| 彩色面积极小（量出来 0.1%） | 全屏只有深蓝和粉两种颜色，各用在一处 |

没有照搬的：Commons 的题干是英文全大写，中文没有大小写，改为靠字重；它没有选项字母，中文考试习惯有 A/B/C/D，保留但做得很轻。

规范（间距、圆角、字号）不来自参考图，全部用 Astryx 的刻度，字阶由基准 17、比例 1.2 生成。
