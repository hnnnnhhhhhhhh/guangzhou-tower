# 摆放规则：用任何组件、任何风格都能摆好看

v0.1 · 接在 Mobbin 工作流后面用。风格（颜色、字体、圆角）照旧从 Mobbin 参考提炼，每个应用不同；组件用什么都行。这一份只管**怎么摆**。

## 为什么好看主要靠摆，不靠组件

同一套普通组件，摆得好和摆得乱，差别在这五件事：

1. **间距有规律**：组内紧、组间松，同类东西间距一样。
2. **对齐**：所有东西靠同一条左边线。
3. **主次**：一屏只有一个最显眼的东西，其余明显退后。
4. **安静**：每个组件身上的装饰（阴影、描边、底色、图标）减到最少。
5. **一致**：同一种东西在每一屏长得一样。

下面每条规则都和组件、主题无关，而且都能量出来。

---

## 一、间距

**P1 只用一套刻度。** 所有间距只能取 4、8、12、16、24、32、48。没有 10、14、18、20 以外的随手数（20 允许，只用于页面左右边距）。

**P2 组内小、组间大，至少差一倍。**

| 关系 | 间距 |
|---|---|
| 一个东西内部（标题和它的说明） | 4 |
| 同组的几个东西（清单行之间、标签之间） | 8–12 |
| 组与组（区块之间） | 24–32 |
| 页面左右边距 | 16 或 20，全应用一致 |

量：任意相邻两个区块的间距，必须 ≥ 区块内部最大间距的 2 倍。

**P3 同类东西间距相同。** 一个清单里每行的高度、上下留白一样；几张同类卡片的内边距一样。

**P4 别留“中间的洞”。** 留白应该在区块之间和页面底部，不应该在一个区块中间出现一大片空。

---

## 二、对齐

**P5 一条左边线。** 页面上的标题、正文、清单文字都靠同一条左边线。图标、勾选框、头像放在这条线的左边或右边，不能让文字的左边忽进忽出。

量：所有文字块的左边缘 x 坐标，去重后不超过 3 个值（页面边线、清单文字缩进、卡片内边线）。

**P6 一行里的东西居中对齐**，数字和单位按基线对齐。

**P7 右侧对齐。** 一组行的右侧内容（价格、状态、箭头）靠同一条右边线。

---

## 三、主次

**P8 一屏一个焦点。** 最大、最重、颜色最强的东西只有一个，而且是用户此刻要看或要做的那件事。

量：字号最大的文字只有一处；强调色的实底只有一处。

**P9 拉开层级只用三个手段，按顺序用：** 字号 → 颜色深浅（主要 / 次要）→ 字重。不要靠加框、加底色、加图标来拉层级。

**P10 字号最多四档，相邻两档至少差 1.25 倍。** 15 和 16 同时出现就是没有层级，只是乱。

**P11 次要文字统一用一个灰。** 不出现第三、第四种灰。

---

## 四、安静：给组件降噪

组件本身丑，通常是装饰太多。对每个组件按顺序做减法，直到再减就看不清它是什么为止：

**P12 降噪顺序**

1. 去掉阴影（浮在内容上方的除外）。
2. 去掉描边（输入框、未选中的可选项除外）。
3. 去掉底色（真正需要区分的块除外）。
4. 去掉图标（能靠文字说清的）。
5. 去掉圆角差异（全应用只留两档：容器一档、控件一档）。
6. 去掉颜色（状态和主操作除外）。

**P13 一块东西只用一种方式和背景分开**：底色、描边、阴影三选一。

**P14 同类东西用清单，不用卡片。** 卡片是最“吵”的容器，一屏最多 3 张。

**P15 组件默认样式不合风格时，改样式，不换组件。** 比如组件库的按钮默认是蓝色圆角 4，而风格是黑色直角：改它的颜色和圆角，不另造一个按钮。

---

## 五、一致

**P16 同一种东西每屏长得一样。** 第一屏的清单行和第三屏的清单行，高度、字号、间距、右侧排法完全相同。

**P17 全应用只有一种主按钮、一种次按钮。**

**P18 同一种操作用同一个图标和位置。** 返回永远在左上；关闭永远在右上。

---

## 六、和 Mobbin 参考对照

摆完之后，和第 4 步选的参考图放在一起，逐项比这五个数。差得多的回去改：

| 比什么 | 怎么比 |
|---|---|
| 页面左右边距 | 参考是 16 还是 20，我的是多少 |
| 区块间距 / 区块内间距的比例 | 参考大约几倍，我的几倍 |
| 首屏有几个区块 | 参考几个，我的几个 |
| 首屏用了几种颜色 | 参考几种，我的几种 |
| 最大字和正文的字号比 | 参考几倍，我的几倍 |

这一步比“看起来像不像”可靠：五个数对上了，即使组件不一样，整体的松紧和节奏也会接近参考。

## 在工作流里的位置

```
澄清 → 选首页类型和信息结构 → Mobbin 选参考、提炼风格（不变）
     → 用组件搭（组件不限）
     → 【摆放规则】按 P1–P18 调间距、对齐、主次、降噪、一致
     → 【和参考对照】比五个数
     → 检查 → 交付
```

## 能自动量的

| 规则 | 量什么 |
|---|---|
| P1 | 所有 margin、padding、gap 是否在刻度里 |
| P2 | 相邻区块间距 ≥ 区块内最大间距 × 2 |
| P5 | 文字块左边缘的不同 x 值个数 ≤ 3 |
| P7 | 同一清单各行右侧元素的右边缘是否一致 |
| P8 | 最大字号出现几处；强调色实底出现几处 |
| P10 | 字号档数 ≤ 4；相邻档比 ≥ 1.25 |
| P11 | 次要文字颜色种数 = 1 |
| P13 | 同一元素既有描边又有阴影 |
| P14 | 带底色或阴影的同类块 ≤ 3 |
| P16 | 不同屏的清单行高度、字号是否相同 |
| 第六节 | 五个数和参考的差 |
