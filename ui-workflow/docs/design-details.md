# 细节规则：圆角、边界、数字、字重、字体、图片

这些规则是“死”的：不需要品味，照做就对，大部分可以自动检查。
来源：设计师对 trip-together 和 driving-quiz 两次产出的反馈（2026-11-12）。写法沿用 apps-builder 设计经验的格式。
里面的具体数值（2px、小一档）是这位设计师给的做法，换团队可以改数值，规则本身不变。

---

## D01 · 圆角嵌套要同心

- **问题**：卡片圆角 42，里面的缩略图圆角 18，两条弧线不平行，角上看着是歪的。
- **规则**：里层圆角 = 外层圆角 − 两者之间的间距。算出来小于 4 就用 4 或直角。
- **例子**：外层 42、间距 12 → 里层 30。外层 24、间距 16 → 里层 8。
- **例外**：外层是胶囊（全圆）时，里层也用全圆或正圆；里层不贴边（四周间距明显大于圆角）时不必同心。
- **自查**：找出每一处“圆角里套圆角”，逐个算一遍。
- **自动检查**：可以。量父子元素的圆角和间距，差值超过 2 报警。

## D02 · 一块东西只用一种方式和背景分开

- **问题**：卡片同时有底色、描边和阴影，显得脏、显得重，而且每张卡都这样就成了“一定会有描边”。
- **规则**：底色差、阴影、描边三选一。
  | 情况 | 用什么 |
  |---|---|
  | 白卡在灰底上 | 只靠底色差，不描边、不加阴影 |
  | 白卡在白底上 | 轻阴影，或一条细线，只选一个 |
  | 浮在内容上方的东西（弹层、悬浮栏） | 阴影 |
  | 可选中的小控件（未选中的标签、日期格） | 细描边，不加阴影 |
- **例外**：虚线边框是一种状态（未确定、建议、待添加），不算装饰，可以单独使用。
- **自查**：逐个看每种容器，数它用了几种分隔手段。
- **自动检查**：可以。同一个元素同时有可见边框和阴影就报警。

## D03 · 日期分三段排，不整段打出来

- **问题**：“11/20”“11月3号”当成一串普通文字打，数字和分隔符一样大一样重，不精致。
- **规则**：月、分隔符、日是三段。分隔符的字号比数字小一档、颜色用次级色；分隔符两侧各留 2px；数字用等宽数字。
- **例外**：写在句子里的日期（“11 月 20 日出发”）照常写。
- **自动检查**：部分可以。查界面文字里有没有整段的 `数字/数字`。

## D04 · 货币符号和单位跟数字底对齐、小一档

- **问题**：“¥128”“3 天”把符号、单位和数字用同一个字号一起打。
- **规则**：符号和单位比数字小一档，和数字**基线对齐**（不是顶对齐，也不是居中），与数字间距 2px；单位用次级色。
- **例外**：正文句子里的金额照常写。
- **自动检查**：部分可以。查大号数字旁边有没有同字号的 ¥、$、%、“个 / 天 / 题”。

## D05 · 粗体是稀缺的

- **问题**：标题、卡片名、按钮、标签全是粗黑体，满屏都在喊，反而没有重点。
- **规则**：
  | 用途 | 字重 |
  |---|---|
  | 正文、说明 | 常规（400） |
  | 标题、卡片名、按钮 | 比常规稍重（500 或 600） |
  | 全屏的主角（一处） | 粗（700） |
  不用 800、900。一屏里粗体的文字不超过一处，面积不超过首屏文字的一成。
- **例外**：数字主角（倒计时、金额、分数）可以用粗；品牌标志不受限。
- **自动检查**：可以。统计可见文字里字重 ≥ 700 的占比，超过阈值报警；出现 800 以上直接报错。

## D06 · 一屏一种字体，衬线和无衬线不混排

- **问题**：题干用黑体、选项用宋体，两种字体大面积交替出现。
- **规则**：一个界面只用一个字体家族。衬线体、手写体、装饰体只允许用在一处小面积上（品牌字、一个大数字、一句引语），不用于正文、选项、列表、按钮。
- **例外**：内容本身是引文或诗文的阅读类产品，正文可以整体用衬线，那时其他地方不再混入无衬线的大标题。
- **自动检查**：可以。统计可见文字里衬线与无衬线各占多少，两边都超过一成就报警。

## D07 · 有图就用真图，没有图就空着

- **问题**：用表情贴纸顶替地点图片，所有景点都是同一个鸟居。
- **规则**：
  1. 内容对象（地点、商品、菜、作品）需要图时，先检索真实图片。
  2. 检索到的图要核对是不是这个对象，再按图位的比例裁切。
  3. 检索不到就留空占位，并保留“暂无图片”的可读标签，不用表情或色块假装有图。
  4. 表情贴纸只做小装饰（类型标记、空状态、奖励），不顶替内容图。
- **注意**：检索来的图有版权，只能用允许使用的来源，并保留出处。
- **自动检查**：部分可以。查内容图位里是不是放了贴纸。

## D08 · 头像用真实的，没有就用首字

- **规则**：用户自己上传或平台账号已有的头像，直接用。没有时用“名字的一个字 + 一个固定颜色”，或者一套授权的插画头像。
- **不做**：不从网上找真人照片来当示例用户的头像。那是别人的肖像，不能拿来用。
- **自动检查**：不需要。
